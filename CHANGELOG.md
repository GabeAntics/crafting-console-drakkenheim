# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-08-12

### Added
- Added an actors compendium with an actor that holds all possible recipes, so that it is visible via the "View Taught Recipes" option.

## [1.1.0] - 2026-08-11

### Changed
- Updated module compatibility to support Foundry v13 through v14.

## [1.0.0] - 2026-08-11

### Added
- Initial release of the Crafting Console - Drakkenheim content module.
- Item and macro compendium packs for Drakkenheim crafting content.
- Ingredient generation macro and supporting assets.
